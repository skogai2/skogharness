## Learnings
- Plugins cannot ship auto-loaded rules; only `.claude/rules/` and `~/.claude/rules/` load on their own.
- A herdr worker is a full Claude session, so it receives the harness SessionStart orientation ("next claimable…"); worker packets must say explicitly that it is not the lead.
- `git diff` output shape is user-configurable (mnemonicPrefix, noprefix, color, external diff); any parser must pin `--src-prefix/--dst-prefix/--no-color/--no-ext-diff`.
